# FoodScope 行业媒体与商业信号源候选池

## 1. 文档定位

本候选池用于 FoodScope Horizon 食品行业版的来源筛选，核验日期为 2026-07-23。它不是一期最终接入清单，也不意味着下列站点均可直接抓取。候选池先尽量覆盖食品产业链和目标市场，之后由产品负责人逐个决定保留、备用、仅发现或淘汰。

当前共收录 **120 个候选**：

- 97 个全球、欧美及日韩行业媒体候选；
- 11 个东南亚及亚太区域媒体候选；
- 12 个数据、研究、协会或产业组织型商业信号源。

候选池使用固定 ID。后续筛选只需记录 ID 与结论，避免因名称相似、改版或排序变化造成歧义。

### 1.1 初筛标签

- **A**：优先进入 14 天试跑，具备较强行业相关性、更新频率和商业信号密度。
- **B**：第二批试跑或细分补位，价值明确，但覆盖较窄、更新较慢或与其他候选重叠。
- **C**：暂不作为常规直连源；可能存在重付费墙、高赞助密度、访问限制，或本身属于研究公司、协会和展会。可作为发现查询、趋势报告或交叉验证线索。

初筛标签不是内容可信度等级。任何来源中的赞助稿、供应商观点和新闻稿仍需单独标记；法规、召回和食品安全结论仍必须回链官方证据。

## 3. 逐个筛选的记录方式

每个候选最终记录一个决定：

| 决定 | 含义 |
|---|---|
| `keep` | 进入一期 20 个行业媒体直连名额 |
| `backup` | 保留为同类来源故障或内容不足时的替补 |
| `discovery_only` | 不抓正文，只用于查询发现、报告线索或交叉验证 |
| `reject` | 一期不使用，并记录淘汰原因 |

建议逐个筛选时同时记录以下字段：

```yaml
candidate_id: M001
decision: keep
reason: 综合覆盖与商业信息密度高
direct_mode: html_metadata
language: en
paywall: partial
sponsored_content: label_required
overlap_group: foodnavigator_network
reviewer: product_owner
reviewed_at: 2026-07-23
```

## 4. 入选前的 14 天试跑

人工初筛为 `keep` 或 `backup` 的来源仍需通过试跑。每个来源至少统计：

- 抓取成功率与发布日期可解析率；
- 日均候选数、有效食品行业内容数和最终入报数；
- 商业/技术内容占比；
- 与其他来源的事件重复率；
- 该来源独有的有效事件数；
- 新闻稿、赞助稿和供应商观点占比；
- 付费墙、robots、登录和正文授权限制；
- 单条采集与 AI 处理成本。

优先保留“有效独家信号多、商业价值高、抓取稳定”的组合，而不是机械保留流量最大或更新最多的站点。同一媒体集团、同一域名或高度重叠的垂直站点可以共享适配器，但仍需分别衡量内容价值。
